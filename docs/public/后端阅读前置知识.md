# 后端阅读前置知识

如果已经会 Java 基本语法，想读懂本项目后端运行逻辑，建议先补下面这些内容。

## 必学

1. Spring Boot 基础
   先理解应用启动、Bean、依赖注入、`@Service`、`@RestController`。
2. Spring MVC / REST 接口
   了解请求怎么从 URL 映射到 Controller 方法，请求体怎么绑定到 Java 对象。
3. DTO 和 `record`
   读懂项目里的请求对象、响应对象、数据传递方式。
4. 异常处理和统一返回
   理解为什么抛异常后会自动返回统一格式的 JSON。
5. Java 集合与 Stream
   重点是 `List`、`Map`、`Set`、`stream()`、`toList()`、`toMap()`。

## 结合本项目特别要懂的

1. `@PostConstruct`
   这个项目会在启动时加载 CSV 种子数据。  
2. 内存存储
   当前没有数据库，仿真结果和推荐结果都先放在内存里。
3. 并发安全基础
   至少认识 `ConcurrentHashMap` 和 `AtomicLong`。
4. 文件 IO 和 CSV 解析
   因为静态参数主要来自 `data/task-a` 下的 CSV 文件。

## 业务和算法层面

1. 离散时间仿真
   这是按时间步推进的仿真，不是真实多人并发执行。
2. 排队模型基础
   重点理解队列长度、服务率、等待时间、拥挤度。
3. 打分与启发式决策
   项目里很多选择不是写死规则，而是根据多个因素打分后再决定。
4. 随机性与可复现
   要理解随机种子、随机抽样，以及“有随机但可复现”的实现思路。

## 建议学习顺序

1. Spring Boot + Spring MVC
2. DTO / `record` / 参数校验 / 异常处理
3. Java 集合与 Stream
4. 文件读取和 CSV 数据组织
5. 仿真与排队模型基础
6. 推荐、分流里的打分逻辑
