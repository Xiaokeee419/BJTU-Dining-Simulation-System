## 分流优化流程

1. 读取一组 `strategyParameters`
2. 基于当前参数生成分流建议
3. 用分流建议重跑仿真
4. 计算指标和 loss
5. 记录本轮参数、结果、最优状态
6. 继续下一轮随机搜索或模拟退火

### 第一版优化方法

- 基线方法：随机搜索
- 主方法：模拟退火
- 输入：`baseRunId`、`strategyParameters` 初值、迭代次数、随机种子
- 输出：最佳参数、最佳 loss、每轮迭代历史、前后对比指标

## 优化任务执行方式

### `POST /api/v1/optimizations/evaluate`

- 输入：`baseRunId` + 一组 `strategyParameters`
- 行为：单次生成分流建议 -> 重跑仿真 -> 计算指标和 loss
- 输出：
  - 本次参数
  - 本次 loss
  - 分流建议
  - 仿真对比指标

### `POST /api/v1/optimizations/run`

- 输入：`baseRunId`、初始参数、优化方法、迭代次数、随机种子
- 行为：
  - 随机搜索生成初始候选
  - 模拟退火持续扰动参数
  - 每轮调用 evaluator
  - 每轮写入 `OptimizationStore`
- 输出：
  - `jobId`
  - 初始状态

### `GET /api/v1/optimizations/{jobId}`

- 输出：
  - 任务状态：`PENDING/RUNNING/COMPLETED/FAILED`
  - 当前轮次
  - 当前最优 loss
  - 最优参数摘要

### `GET /api/v1/optimizations/{jobId}/iterations`

- 输出：
  - 每轮参数快照
  - 每轮 loss
  - 每轮关键指标
  - 是否接受该轮候选

### `GET /api/v1/optimizations/{jobId}/best`

- 输出：
  - 最优参数
  - 最优 loss
  - baseline 与 best 的指标对比
  - 对应的分流建议
